# Digital Twin – Predictive Maintenance

A portfolio project demonstrating Digital Twin concepts for industrial filter systems.

## Project Goal

Build a physics-informed predictive maintenance system that:
- Simulates filter clogging behavior using physical models
- Generates realistic synthetic sensor data
- Predicts Remaining Useful Life (RUL) using ML
